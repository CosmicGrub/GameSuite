# Preliminary trademark screen of working titles

**This is a preliminary screen from public web searches only. It is NOT legal advice and is NOT a clearance.**
The owner must run official searches (USPTO TESS/Trademark Search, EUIPO eSearch plus, WIPO Global Brand Database,
and the national office of every launch market) and consider a trademark attorney before any store listing.
Search date: 2026-11-28. Method: one public web search per name (exact phrase, "game app"/"board game" wording), reading
the App Store / itch.io / store hits the engine returned. Google Play and Steam were not searched directly, and the search
tool does not index registers, so a "no hit" below means only "no hit in this search".

Risk: **High** = same or near-identical name in the same field, or famous mark; **Medium** = same name in an adjacent field or
a very close name; **Low** = only generic or loosely similar names found.

## Notes
- "Chutes and Ladders" and "Snakes and Ladders", "Monopoly", "The Game of Life", "Candy Crush" are third-party marks; keep the
  game designs, rules text and store copy free of them (the "Slide and Climb" alternative list deliberately avoids them).
- Prioritise renaming or clearing the five High-risk titles (Gem Cascade, Territory Wars, Bump and Run, Stack Zoo, plus Property
  Tycoon at Medium-High) before any store listing. Internal package names (`bump-run`, `life-road`, ...) need not change; the
  player-facing names and ES translations do.
- Also check the Spanish names and the short store title, which are separate marks in practice.
- Alternatives above were not searched; they are brainstorm candidates and need the same screen.
- Not done: Google Play and Steam direct searches, national trademark registers, domain and social-handle availability.
