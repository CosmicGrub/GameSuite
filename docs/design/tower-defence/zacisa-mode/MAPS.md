# Bot Bastion: maps (our own layouts)

Status: DESIGN DRAFT, 2026-11-22. All twelve layouts are original geometry; none reproduces any source-game map (whose layouts we could not obtain anyway). Generated from the same data as `docs/design/canvas/ZSMaps.dc.html`, so the diagrams and the board agree.

## Conventions

- Arena is 16 x 9 units (16:9). Coordinates below are normalised 0..1 (x right, y down); lanes are polylines (smoothed with Catmull-Rom at render time, straight segments in the engine).
- ASCII grid is 64 x 18 cells. `=` lane (enemy corridor), `o` build node, `S` lane entry, `C` Core, `~` void hazard (not buildable, not walkable), `.` open space.
- Nodes were generated by a deterministic rule (candidates 0.95 u beside each lane every 0.55 u; no closer than 0.72 u to a lane, 1.35 u to the Core, 1.2 u to each other; outside voids; inside arena bounds) and are listed per map so a build team gets identical coordinates. A designer may hand-tune later; keep node count within 12 to 22.
- `pace` multiplies enemy speed so the end-to-end traverse time of a base Drifter stays about 16 to 44 s (0.96 u/s x pace). `trav` is that time.
- Unlock by total stars (see SPEC section 8).

## Skiff rim path

The Skiff patrols a rounded rectangle inset 0.4 u from the arena edge (about 44 u perimeter at 0.22 W/s = 3.5 u/s, a lap in about 12 s). It breaks off to chase the closest enemy inside its range and returns to the rim afterwards. Where lanes touch the rim it flies over them.
