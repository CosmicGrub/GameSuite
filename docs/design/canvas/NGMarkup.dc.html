New games, five-state pattern

Markup and specs

Every new game follows the same five states so a child or grandparent learns the flow once: set up, start, play, finish, score card.
1 SetupWho plays, one or two game rules, a handicap switch, and one saffron-or-accent Start button pinned to the bottom. Names, tokens and avatars are chosen here, never mid-game. Pre-readers see icons and big numbers; the grown-up reads the labels.
2 StartA curtain or countdown, never a blank wait. Secret-information games (Draw and Guess, Act It Out) show "Pass to Name" with a press-and-hold reveal, so peeking needs deliberate effort. Echo Pads and Bridge Builders count in with a big 3, 2, 1.
3 Mid-gameOne thing to do per screen. Timers are a ring plus a number, milestones only for screen readers. Waiting is shown in words ("Leo's lane is waiting"), never colour alone.
4 Post-gameOne celebration, one primary action (play again). Competitive games name a winner with a podium; cooperative games say "We did it!" or "Try again together". Reduced Motion: no confetti, no pulse.
5 Score cardOne shareable card per game: date, standings, three small stats, one highlight. Card text avoids "loser" wording for kids. Buttons: Save to stickers, Done. Saved cards live in the Sticker book and the Parent dashboard.
Handicap, everywhereA single "extra help" row in setup, same wording and placement in every game: extra roll (Slide and Climb), bonus points for little kids (Draw and Guess, Act It Out), wider spots (Bridge Builders), one free mistake (Echo Pads). Never shown on the score card as a penalty.

Rules for all five
Targets 56 dp or more; pad and zone hit areas 72 dp or more for Echo Pads and Bridge Builders.
No online play and no chat. Same-screen and pass-and-play only this round.
Kids profiles see Slide and Climb, Echo Pads, Bridge Builders; Family games also appear for kids 6 and up.
Every state has a pause that returns to the same state, never to Home by accident.
Text honours the in-app size slider; no fixed font sizes ignoring it.
Score cards render offline and contain no personal data beyond first names the family typed.
