Quality

Auto, High, Balanced, Battery saver. Auto only lowers the user choice, never raises it.
1
Auto explained Plain words, plus the current reason code when it has lowered (THERMAL, LOW_RAM).S
2
Capability readout From detect(rawFacts): graphics class, refresh rate, battery saver. No GPU-string guessing.M
